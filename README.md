The Crims Robbery Bot is a Python-based automation bot built with Playwright for the browser game The Crims. It automates repetitive in-game actions such as robbery attempts, stamina management, stamina refill, and detox handling when addiction becomes too high.

The bot runs in a visible browser window and simulates more natural mouse movements and clicks to make its behavior look less robotic. The user logs in manually, opens the robbery section, and then starts the script. From there, the bot can work with a set robbery limit or run continuously without one.
Features

✅  Automates robbery attempts.
        
✅  Monitors stamina and refills it when needed.
        
✅  Detects high addiction levels and performs detox actions.
        
✅  Simulates human-like mouse movement and clicking.
        
✅  Supports both limited and unlimited robbery runs.
